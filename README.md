# nirman-os.in

The NirmanOS website: static files served by GitHub Pages (`CNAME`: nirman-os.in).

- `index.html`: home, with what works today in the pilot, the agents, Twinbook and how to join.
- `technical.html`: how a message travels, Twinbook's signed messages and receipts, who does what, and the stack.
- `workflow.html`: the order story between two businesses.
- `privacy.html`: data and privacy.
- `plan.html`: the needs planner.

Colours are a strict 60:30:10 system (cool white, ink navy, blue), defined as tokens in `v2.css`. Fonts are served from `fonts/` (SIL Open Font License); the site makes no requests to other servers. Hindi first, with English via the language switch or `?lang=en`.

The source and build scripts are kept outside this repository.
